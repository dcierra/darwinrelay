# Code of Conduct

DarwinRelay follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) version 2.1.

Project participants are expected to keep technical discussion professional, specific and focused on the work. Harassment, personal attacks, discriminatory behavior, threats, doxxing and deliberate disruption are not acceptable.

For ordinary moderation concerns, contact the maintainer through the GitHub profile for `@dcierra`. Security vulnerabilities should use GitHub private vulnerability reporting instead of moderation channels or public issues.
